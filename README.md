# 课堂点名（Classroom Roll Call）

一款面向**中小学及高校教师**的课堂随机点名桌面软件。纯白简洁界面，一键随机抽取，内置公平性与「重点关照」机制，支持语音播报、表格导入、课时模式与防学生密码保护。**免安装便携版，双击即用，无需任何环境配置。**

## ✨ 功能特性

- **一键点名**：点击主界面任意位置即开始，名字快速滚动约 1.5 秒后定格；动画中再点一下立即出结果。
- **单 / 多人点名**：一次可抽 1~N 人；多人结束时显示「抽中 N 人」及名单列表。
- **字号自适应**：根据人名长度与人数自动调整字号，单名不换行、整体不溢出。
- **公平抽取机制**：不重复、降低重复率、重点关照、跨轮错位等多重算法保证公平。
- **重点关照**：对需要多关注的学生，抽中概率渐进提升，且每个周期内「必定抽中」。
- **语音播报**：抽中人数 ≤ 5 时自动朗读人名（调用系统语音，无需联网）。
- **表格导入**：直接选择或拖入 Excel / CSV 文件，自动提取任意位置单元格中的人名。
- **名单管理**：查看、查找、增删、纠错人名池。
- **课时模式**：按一整节课为大周期，适合按课时统计去重。
- **防学生密码**：防止学生偷偷修改「重点关照」设置。

## 📸 界面概览

- **主界面**：纯白背景，中央「点击开始点名」大字，右下角为设置图标（⚙）与「开启新一课」图标（＋）。
- **设置界面**：人名数据导入、基础设置（生效方式 / 语音 / 允许重复 / 单次人数 / 降低重复率 / 防学生）、使用教程入口。
- **高级设置**：重点关照名单管理、单人 / 多人周期配置。

## 🚀 快速开始（安装教程）

### 方式一：直接使用（推荐，面向教师）

1. 打开本仓库 **Releases** 页面（仓库首页右侧的「Releases」标签）。
2. 下载 `课堂点名.exe`（免安装便携版）。
3. **双击运行**，无需安装、无需任何依赖。
4. 首次运行若 Windows 弹出「已保护你的电脑」，点「**更多信息 → 仍要运行**」即可（未签名软件的常态提示）。

> 说明：打包好的 exe 体积较大（约 75MB），统一通过 **Releases** 发布，不进入源码仓库，保证 `git clone` 轻量快速。

> 语音播报依赖 Windows 自带中文语音（Win10/11 默认内置「Microsoft Huihui」）。若无声，请到「设置 → 时间和语言 → 语音」确认已安装中文语音包。

```bash

git clone https://github.com/<你的用户名>/classroom-rollcall.git
cd classroom-rollcall

# 2. 安装依赖（需 Node.js ≥ 18，建议 20+）
npm install

# 3. 启动
npm start
```

## 🎯 点名机制与算法

核心抽取引擎位于 `src/logic.js`（纯逻辑，无 UI 依赖，可在浏览器 / Node 中运行），全部规则均有单元测试覆盖（`test-logic.js`，32 项断言）。

### 1. 基本抽取

- **单人**：从候选池中随机抽取 1 人。
- **多人**：一次抽取 N 人，同一批内不重复。
- **超限处理**：设定人数大于总人数时，按总人数执行。
- **人数不足**：多人点名剩余不足时按剩余人数抽取，不自动开启下一轮。

### 2. 不重复机制（允许重复 = 关）

被抽中的人名移出剩余池，直到池空才自动开启新一轮。为提升「先后位置」的公平感，剩余池采用**洗牌队列 + 跨轮错位**：

> 新一轮洗牌时，把「上一轮靠前的一半名字」自动挪到「这一轮的后半段」。实测将位置波动缩小约一半，避免某名字连续多轮总靠前。

### 3. 降低重复率（默认关，全局生效）

仅在「允许重复」时生效。开启后，**最近 `N` 次**（默认 3，可配置）出现过的名字暂时排除，池不足时允许重复。该规则对普通名与重点关照名**一视同仁**。

### 4. 重点关照（渐进概率）

仅在「允许重复」时生效，每个关照人名**独立计数**。

- 初始概率与普通人相同。
- 周期内**每未抽中一次，概率按以下公式递增**：

```
权重 = max(1, 池子人数 × mult)
mult = 命中 ? 0.12 : max(0.12, 2 × ((k - 1) / M)²)
M    = ceil(周期 / 2)          // 中间项，随自定义周期自适应
```

- 第 1 次即有约 11% 基础概率（保证每次都有可能），随后**平方加速**，概率峰值落在**中间项 M 与 M+1**（略往后偏）。
- **周期末（第 N 次）仍未出现 → 100% 强制出现**。
- 周期内**一旦抽中 → 概率强制降回初始，且本周期不再递增**。
- 周期数单人默认 **5 次**、多人默认 **4 次**，可在高级设置中自行调整。

> 效果（31 人池、周期 5、2000 次统计）：第 1 次 11% · 第 2 次 17% · 第 3 次 34%（峰值）· 第 4 次 27% · 第 5 次保底 11%。

### 5. 多人关照顺延

多人模式下，若多个关照名同时到期，**一次只随机强制其中一个**，其余**顺延**——本次不参与选择、不计入周期计数，直到后续被强制。

### 6. 课时模式（大周期）

- 按**一整节课**为一个大周期；开启新一课有两种方式：每次打开软件时询问，或点主界面右下角「＋」图标。
- 降低重复率改为**按课时计数**（可选 0.5 / 1 / 2 / 3 / 4 / 5 课时）：
  - 整数课时：最近 N 节课内不重复。
  - **0.5 课时**：按计算机**实时时间**每半小时一个周期（以「开启新课时」时刻为基准对齐，关闭软件再打开超过半小时会按半小时折算；选新课时重新计时）。
- 重点关照：本课时内点到该人名后，本课时内不再重复。

### 7. 防学生密码保护

- 默认关闭；开启需设置密码。
- 设置密码后**立即锁定**：修改「重点关照」或关闭本功能均需验证密码。
- 密码验证正确后，**半小时内免验证**。

### 8. 语音播报

仅在**点名人数 ≤ 5**且语音开关开启时播放，调用 Windows 系统语音引擎（无需联网）。

## 🛠 开发者部署教程

### 环境要求

- Node.js ≥ 18（建议 20+）
- npm
- （可选）打包 Windows 版需要 Windows 环境

### 常用命令

```bash
npm install      # 安装依赖
npm start        # 本地运行调试
npm test         # 运行算法单元测试（test-logic.js，32 项断言）
npm run dist     # 打包为便携版 exe（输出到 dist/）
```

### 生成应用图标（首次打包前）

仓库不含二进制图标文件，首次打包前运行：

```bash
python build-icon.py
```

会在 `assets/` 下生成 `icon.ico` 与 `icon-256.png`（需 `pip install pillow`）。

### 打包产物

- `dist/ClassroomRollCall-1.0.0-portable.exe`：单文件便携版，双击即用。
- `dist/win-unpacked/课堂点名.exe`：解包版目录。

> 打包说明：`package.json` 中 `build.win.signAndEditExecutable` 设为 `false`，由 electron-builder 的 NSIS 阶段直接嵌入图标与版本信息，规避无管理员权限时 winCodeSign 解压符号链接失败的问题。
